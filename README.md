# Wingate Learning Lite

תבנית מוצר קלה לאפליקציות לימוד — עברית, RTL, מובייל תחילה.
המטרה: להקים מקצוע חדש מהר, בלי לשכתב רכיבים ובלי להעתיק ריפו ביד.

התוכן שכאן הוא **תוכן דוגמה מזערי בלבד** — לא חומר לימוד אמיתי.

## הרצה

```bash
npm install
npm run dev        # פיתוח
npm run build      # typecheck + build
npm run lint       # oxlint
npm run preview    # הרצת ה־build
```

## מה יש בפנים

**מעטפת מוצר משותפת** — כותרת קבועה, ניווט עקבי, טיפוגרפיה ב־Heebo (מתארחת מקומית),
PWA להתקנה בטלפון (manifest + service worker), RTL מלא ומובייל תחילה.

**מסע תלמידה** — כניסה, בית עם "ממשיכים מהמקום שבו עצרת", מפת יחידות
(נעולה / פתוחה / הושלמה), יחידה ותחנה אחת בכל מסך, שמירה, הגשה,
החזרה לתיקון, הגשה מחדש, אישור ופתיחת היחידה הבאה.

**צד מורה** — רשימת התלמידות במרכז המסך, רמזור מילולי וצבעוני
(לא התחילה · בתהליך · ממתינה לבדיקה · חזרה לתיקון · הושלם ואושר),
פתיחת תלמידה, צפייה בתשובות, משוב, אישור ופתיחת היחידה הבאה.

## מבנה

```
src/
  content/          ← מה שמשנים לכל מקצוע
    course.ts       קובץ התוכן היחיד: יחידות, תחנות, שדות תשובה, חובה
    theme.ts        שם המקצוע, תג אחוזים, צבע, אייקון, מטאפורת מילים
    students.ts     רשימת תלמידות להדגמה
  data/             ← שכבת הנתונים
    types.ts        מודל התוכן, מודל ההתקדמות ו־interface של DataAdapter
    localAdapter.ts מימוש מקומי (localStorage) להדגמה בלבד
    AppProvider.tsx חיבור התוכן + ה־adapter לאפליקציה
    session.ts      בחירת משתמש להדגמה (לא אימות אמיתי)
  core/             ← ליבה גנרית, בלי שום קוד מקצועי
    logic/          סטטוסים, נעילה/פתיחה, שלמות תחנה, סיכום מסלול
    ui/             סטטוס, התקדמות, שדה תשובה, באנרים, מצבי טעינה/ריק/שגיאה
  screens/          מסכים: כניסה, בית, יחידה, מורה, תלמידה אצל המורה
  app/              מעטפת ומעברי ניווט
  styles/           tokens.css (צבעים, מרווחים, רדיוסים) + app.css
scripts/
  new-subject.mjs   יצירת אפליקציית מקצוע חדשה מהתבנית
  make-icons.mjs    יצירת אייקוני ה־PWA מקוד
docs/
  NEW_SUBJECT.md    איך מקימים מקצוע חדש
  screenshots/      צילומי מובייל ודסקטופ
```

עיקרון: **אין מספרים קשיחים**. מספר היחידות, מספר התחנות, סוגי השדות ומה חובה —
הכול נגזר מ־`src/content/course.ts`. שינוי הקובץ הזה משנה את המוצר בלי לגעת ברכיב אחד.

## מקצוע חדש

```bash
node scripts/new-subject.mjs ../wingate-math --name "מתמטיקה" --accent "#2F5FA6" --badge "35%"
```

הפירוט המלא: [docs/NEW_SUBJECT.md](docs/NEW_SUBJECT.md).

## מה בכוונה לא נמצא כאן

Firebase / Supabase, אימות אמיתי, AI, עורך תוכן, import/export, תעודות,
ניהול כיתות, deploy וחיבור ל־Hub. שכבת הנתונים מוגדרת כ־interface אחד
(`DataAdapter`) כדי שחיבור אמיתי יהיה החלפת מימוש — לא שכתוב מסכים.

## בדיקה

```bash
npm run build
npm run preview -- --port 4310 &
PW_CHROMIUM=<נתיב לכרומיום> npm run qa    # מסע מלא + צילומי 375/1440
```

`scripts/qa-journey.mjs` עובר את כל המסע (כניסה → מילוי → הגשה → החזרה לתיקון →
הגשה מחדש → אישור → פתיחת היחידה הבאה), בודק RTL, היעדר גלילה אופקית ומצבי טעינה,
ושומר צילומים ל־`docs/screenshots`. Playwright אינו תלות של התבנית.
