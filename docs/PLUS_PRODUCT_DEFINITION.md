# פלוס — הגדרת מוצר (MVP)

**שם עבודה:** פלוס · **כותרת משנה:** הכסף שלך. הדרך שלך. העתיד שלך.
**משתמשת ראשית:** אגם, נערה ישראלית בת 14.

## 1. מטרת המוצר

פלוס אינה אפליקציית מסחר ואינה מבטיחה התעשרות. היא מאמנת ארבע יכולות:

1. להרוויח כסף באופן חוקי, בטוח ומתאים לגיל.
2. להבין לאן הכסף הולך.
3. לחסוך בהתמדה למטרות אמיתיות.
4. ללמוד השקעות ארוכות טווח לפני ביצוע השקעה אמיתית.

**מדד הצלחה:** פעולות בעולם האמיתי — הכנסה ראשונה, חיסכון ראשון, מטרה שהושגה,
השלמת שיעור, שיחה עם ההורים, הפקדה עקבית. לא כמות כניסות לאפליקציה.

**המודל הכלכלי שהמוצר מלמד:**
הכנסה ← חלוקה מתוכננת (50% עתיד / 30% מטרות / 20% כיף, ניתן לשינוי בסך 100%) ←
חיסכון ← למידה ← השקעה עקבית לטווח ארוך. המנוע בגיל 14: השתכרות + שיעור
חיסכון + זמן + התמדה. לא "מניה מנצחת".

## 2. עקרונות בטיחות (חוזה מוצר)

- אין הבטחות תשואה, אין המלצה על נייר ערך, אין מסחר אמיתי, אין חיבור בנקאי.
- אין מינוף, הלוואות, הימורים, מסחר יומי, ואין תגמול על סיכון או בדיקות שוק.
- השקעה אמיתית מוצגת תמיד כפעולה עם הורה/אפוטרופוס דרך גוף מפוקח.
- מידע חוקי/מיסויי הוא חינוך כללי, מתוארך ("עודכן לאחרונה") עם קישור למקור רשמי.
- אין איסוף פרטים מזהים (שם פרטי/כינוי בלבד). אין קהילה, צ'אט או פרסום הכנסות.
- רעיונות עבודה מלווים בכללי בטיחות: אנשים מוכרים, ידיעת הורה, ללא מפגש לבד
  עם זר, ללא מסירת פרטים.
- אין leaderboard והשוואות לאחרים. הישגים על פעולות בריאות בלבד.

## 3. מבנה המידע

- **Transaction** — הכנסה/הוצאה/חיסכון/מתנה/החזר; סכום (אגורות), תאריך,
  קטגוריה, הערה, חלוקה (עתיד/מטרות/כיף), שיוך למטרה.
- **Goal** — עד 3 פעילות; שם, סכום יעד, תאריך, סיבה, נחסך, הפקדה מתוכננת
  (שבועית/חודשית). כולל "כרית ביטחון" מומלצת (500–1,000 ₪).
- **Lesson/Progress** — 12 יחידות מדורגות; נעילה עוקבת; יחידת השקעות מתקדמת
  נפתחת אחרונה.
- **FirstClientTrack** — מסלול 8 צעדים: שירות ← הצעה ← 5 אנשים מוכרים ← מעקב
  פניות ← עבודה ← תשלום ← המלצה ← סיכום.
- **ParentSettings** — קוד מקומי (hash), אישורי משימות רגישות, תאריך בדיקת
  תוכן, ושיתוף סיכום רק בבחירת אגם.
- **RightsFact** — תוכן מתוארך עם קישור למקור רשמי; מעל 400 יום ⇒ "לבדוק במקור".
- כל הכסף באגורות (int). שמירה מקומית (localStorage) במפתחות נפרדים
  לנתוני משתמשת (plus.user.v1) ולדמו (plus.demo.v1). ייצוא/מחיקה מלאים.

## 4. מסעות משתמש עיקריים

1. **פתיחה:** עד 5 שאלות (בלי פרטים מזהים) ← תוכנית התחלה עם 3 משימות.
2. **הלולאה המרכזית:** בחירת מטרה ← בחירת דרך להרוויח ← משימה ← רישום הכנסה ←
   "חלקי את ההכנסה שלי" ← קידום חיסכון ← שיעור ← בדיקת התמדה בסימולטור ←
   שיתוף ההורים בהחלטה הבאה.
3. **מסך הבית:** עונה על ארבע שאלות — איפה אני, מה היעד, מה הפעולה הבאה
   ולמה — עם פעולה מרכזית אחת, רצף שבועי מבוסס פעולות אמיתיות, ותובנה אחת.
4. **עם ההורים:** רשימת שיחות/פעולות (חיסכון לכל ילד, חשבונות נוער, עמלות,
   נזילות, מתי השקעה) + מצב הורה בקוד מקומי.

## 5. היקף ה-MVP

**בפנים:** Onboarding, בית, להרוויח (8 רעיונות + מסלול לקוחה ראשונה + מחולל
הצעה להעתקה בלבד), הכסף שלי (הזנה ידנית + חלוקה), מטרות (עד 3), אקדמיה
(12 שיעורים), מעבדת השקעות (ריבית דריבית, גילאי התחלה, עמלות, תרחישים,
הפסקת הפקדות), עם ההורים, מרכז זכויות, הישגים, הגדרות (ייצוא/מחיקה/נגישות),
מצב דמו "אגם".

**בחוץ (במכוון):** רשת חברתית, מסחר אמיתי, חיבור בנקאי, סליקה, AI פתוח,
marketplace, analytics/מעקב, שליחת הודעות בפועל.

**טכנולוגיה:** React + TypeScript בתוך הסופר-פרויקט, מודול עצמאי `src/plus/`
עם route ציבורי `/plus/*`. שכבת נתונים מופרדת שניתן להחליף ב-Supabase בעתיד.
RTL אמיתי, מובייל-פירסט, נגישות (44px, ניגודיות, הפחתת תנועה, ARIA).
