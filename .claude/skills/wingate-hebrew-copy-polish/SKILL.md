# Wingate Hebrew Copy Polish Skill

## מטרה
שיפור הכתיבה העברית בממשק אפליקציית Wingate.
הסקיל עורך **מחרוזות UI בלבד** — אינו נוגע בלוגיקה, auth, database, routing.

---

## עקרונות כתיבה לאפליקציית Wingate

### טון וסגנון
- **קצר וישיר** — לא יותר ממה שנחוץ
- **לא רובוטי** — "ברוכים הבאים!" לא "משתמש הזין נתונים בהצלחה"
- **מכבד ולא מתנשא** — סטודנטים, מאמנים ומנהלים — כולם שווים
- **פעיל לא פסיבי** — "הוסף תוכנית" לא "ניתן להוסיף תוכנית"
- **עברית ישראלית** — לא תרגום מילולי מאנגלית

### כללי זהב
| ❌ לא כך | ✅ כך |
|---|---|
| "בצע פעולה" | "בואו נתחיל" |
| "הפעולה הושלמה בהצלחה" | "נשמר ✓" |
| "אין נתונים להציג" | "עדיין אין כלום כאן" |
| "שגיאה התרחשה" | "משהו השתבש — נסה שוב" |
| "לחץ כאן להמשך" | "המשך" |
| "Coming Soon" | "בקרוב" |
| "N/A" | "—" או "לא רלוונטי" |

## שלב 1 — זיהוי קבצי הטקסט

חפש מחרוזות עברית ב:
- `src/components/` — component labels, headings, buttons
- `src/pages/` — page titles, empty states
- `src/locales/` או `src/i18n/` — קבצי תרגום (אם קיימים)
- `src/constants/` — string constants

**אל תחפש ב:**
- `src/auth/`, `supabase/`, `firebase/`, `env`, `routes/`

---

## שלב 2 — קטגוריות לבדיקה

### כפתורים (Buttons & CTAs)
- הפעל מילת פועל: "שמור", "המשך", "צור", "מחק", "ערוך"
- כפתורי ביטול: "ביטול" (לא "לא")
- כפתורי אישור: "אישור" / "בסדר" / "מחק" (לא "Yes")

### כותרות (Headings)
- כותרת ראשית — ברורה, מדויקת, ללא מילות גוזמה
- כותרות משנה — מנחות, לא מדווחות

### מצבי ריק (Empty States)
- הסבר ידידותי מה חסר
- הצע פעולה: "הוסף את הראשון שלך →"
- לא: "אין נתונים", "No items found"

### שגיאות ואזהרות
- **שגיאת validation:** "נא למלא שדה זה" / "מספר הטלפון לא תקין"
- **שגיאת רשת:** "לא הצלחנו להתחבר — בדוק את האינטרנט ונסה שוב"
- **שגיאה כללית:** "משהו השתבש. ניסיון חוזר..."
- לא: "Error 500", "undefined", "null"

### Onboarding
- חם, ממוקד ופעיל
- "בוא נתחיל" → "ספר לנו עליך" → "הכל מוכן 🎉"

### Coming Soon / בניה
- "בקרוב" (לא "Coming Soon")
- "עובדים על זה 🔨"
- "נחזור אליך בקרוב"

### Tooltips והוראות
- משפט אחד, ברור
- "לחץ כדי לערוך את הפרטים שלך"

## שלב 3 — הצגת הצעות לפני עריכה

לפני עריכת **כל** קובץ, הצג טבלת השוואה:

```
## הצעות שיפור — [שם הקובץ]

| מיקום | טקסט נוכחי | טקסט מוצע | סיבה |
|---|---|---|---|
| Button L32 | "בצע שמירה" | "שמור" | קצר וישיר |
| Empty state L87 | "אין נתונים" | "עדיין ריק כאן" | ידידותי |
| Error L103 | "Error occurred" | "משהו השתבש — נסה שוב" | עברית, פעיל |

האם לאשר שינויים אלה? (כן / לא / לשנות)
```

**המתן לאישור המשתמש לפני עריכה.**
